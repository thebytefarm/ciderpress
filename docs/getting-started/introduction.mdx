# Introduction

## What is ciderpress?

ciderpress is a documentation framework for monorepos. Your config file _is_ your site structure — it defines what content exists, where it comes from, and how it's organized. Source files are never modified. ciderpress syncs them into a build directory, injects frontmatter, generates sidebars and navigation, and outputs a static site.

```bash
npx ciderpress dev
```

That's it. One command, working docs site.

## Why ciderpress?

There are great documentation tools — [VitePress](https://vitepress.dev), [Rspress](https://rspress.dev), [Docusaurus](https://docusaurus.io). They inspired ciderpress. Here's what it does differently:

**Zero effort.** Most doc tools need significant setup before they produce anything useful — plugins, theme wiring, sidebar configuration, file restructuring. ciderpress ships with perfect defaults that match the 80% use case. Put markdown in `docs/`, run one command, get a working site with sidebar, navigation, and themes.

**Your structure, not ours.** The config maps to how you already organize your markdown. You describe where your files are and how they should be grouped. You don't restructure your docs to fit the tool — the tool fits your docs.

**AI-friendly by design.** ciderpress auto-generates `llms.txt` and serves every page as `text/markdown` — just append `.md` to any URL.
